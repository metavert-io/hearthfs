# Willow Lane Community Garden: shared files

This folder holds the garden association's working files: board meeting
notes, the plot waitlist, the watering rota, invoices and event invites.

- Plots: 24 raised beds, numbered 1 to 24, plus a shared herb spiral.
- Season: the water is on from 1 April to 31 October.
- Questions about this folder go to the secretary, Lena.
